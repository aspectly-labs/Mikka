`saveRunFile({runId, repoId, path, expectedVersion|sha, encoding, content, operationId})`
- CAS write: 409 when current file version != expectedVersion.
- Atomic: temp file + fsync + rename in same dir.
- Symlink safety: reuse `safeFile(root, path, use)` from packages/daemon/src/coding-workspace/files.ts — it opens each segment, rejects symlinks; for write use add O_NOFOLLOW on final create + verify parent dir fd is inside root (device+mountId).
- Preserve LF/CRLF (eol.ts exists!) and exec bit; encoding utf8|base64.
- Receipt with new file version (sha256 WorkingSourceRevision-style digest), audit entry for create/rename/delete (journal like git.ts entries), idempotent on operationId replay.
- No absolute-path RPC: path always relative to workspace root.

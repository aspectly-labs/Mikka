# Coding Task workspaces on Cloudflare

The product task Worker accepts Cloudflare service-binding calls. It has no public HTTP route. An authorized Mikka service supplies an owner, Workspace, Task, frozen canonical repository, Run, machine operation and expiring lease. Store provider choice at Run admission before binding production calls. The Worker trusts the service binding to enforce Mikka membership, consent and Run ownership. The repository's engineering GitHub Actions identity has no product access.

The owner, Workspace, Task and repository identify the Durable Object and its private R2 prefix. Each Run and operation forms a distinct writing lease. A status request leaves compute asleep. Repeated opens for a live lease reuse the same instance. A new operation cannot displace a live writer. A Workspace runs up to 25 task machines at once (WORKSPACE_MACHINES); admission over the cap is rejected as retryable capacity, never queued. A lease is renewed in five-minute prepaid chunks for as long as Mikka 额度 pays for it; the paid deadline plus a short grace is the only deadline. A separate minute is reserved for checkpointing.

The Worker serializes its file and stop operations. It acknowledges a file write after the official Cloudflare SDK commits a checksum-bearing archive of the workspace directory to R2. Cold restore uses the SDK's integrity check and fails if the expected archive is unavailable. The runtime home and platform login files stay outside the backed-up directory. Repository-local credential stores are excluded. Backup pruning is limited to the current task's prefix and preserves the committed manifest.

The machine's instance type is the billed size recorded at admission (lib/cloud-computer/machine-pricing.ts MACHINE_SIZES, carried by the grant). Sizes above the provider's default 4 vCPU / 12 GiB account limit are quota-gated (#3080): they cannot start until operations records verified provider quota via MIKKA_TASK_MACHINE_16GIB_QUOTA, and an unverified request is billed and started at the largest default-quota size with its request and reason recorded in the machine lifecycle. Grant-free rows start the default standard-3. A run waiting on input keeps its machine and its lease alive until the paid time ends; compute is released only when the lease stops.

Park persists the checkpoint before explicitly stopping compute and releasing capacity. Completion, end, pause, stop-request, task close and lease expiry all converge on that same stop, with the Durable Object alarm as the backstop for lost responses and interrupted cleanup. The restored container has a new process environment. The image uses the same native Claude Code and Codex installer and integrity pins as the Mikka daemon. CI verifies their binaries offline. The private Task process adapter implements Eve's SandboxConnection with independent byte streams, stdin, file operations and process-tree cancellation. Native subscription login, Git delivery, interactive terminal and preview require the product Machine integration and its production acceptance.

For a deployment, provision a private R2 bucket and bind it as WORKSPACES, then wire only the authorized product host to the service. Keep the task Worker off public routes. The Eve host continues to own the public agent/session APIs and portable conversation scratch. See the current implementation/rollout evidence in [the product provider issue](https://github.com/alexj11324/Mikka/issues/1936).

A private service binding supplies the compute lease. The Node host uses its authenticated egress interceptor for file operations and Cloudflare Cap'n Web for full-duplex process I/O. A process owns the task workspace until it exits and the Worker commits the checkpoint. The kernel gives the command its own PID and mount namespaces, removes all Linux capabilities and enables no-new-privileges before applying its environment. The Worker kills surviving writers before archiving. On Durable Object restart the task's live process transport ends; the Worker saves the workspace and closes that lease. A concurrent file operation is rejected while any native writer can change the tree.

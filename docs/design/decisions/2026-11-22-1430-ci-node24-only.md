# CI runs Node 24 only

Status: accepted (Alex, 2026-11-22). Supersedes the CI verification of
[2026-11-18-0300](2026-11-18-0300-node22-everywhere.md).

## Decision

CI no longer runs anything on Node 22. The core and integration unit checks,
the PostgreSQL 17 database shards and the Node.js compatibility workflow
(`local-device-node22.yml`) each run once, on Node 24. The "(Node 22)" check
names are gone; the Node 24 check names are unchanged.

## Why

Every merge candidate ran each of those suites twice. The database shards alone
added four PostgreSQL jobs per candidate, while the merge queue held dozens of
entries and hours of estimated wait. Mikka builds, ships and deploys on 24.

## What this does not change

`engines` (`>=22`), the Eve engine patch and the runtime code from #2817 stay as
they are. Node 22 is no longer verified, so a regression on 22 can merge
unnoticed. Removing the claimed support is a separate change.
